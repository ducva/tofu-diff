# tofu-diff

tofu-diff is a Go terminal viewer for human-readable OpenTofu plan diffs.

## Repository knowledge (OKF)

Before substantive planning, diagnosis, review, or implementation, start at
[`okf/index.md`](./okf/index.md) and read the relevant concepts via
`.agents/skills/okf-context/SKILL.md`. Repository sources remain authoritative
when a draft or stale concept disagrees. After a material change to described
behavior, ownership, architecture, operations, or conventions, update the affected
OKF concepts in the same change using `.agents/skills/okf-maintainer/SKILL.md`.
